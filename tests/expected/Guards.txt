Usage: Guards <case>, where the case is one of:
  restore-order        an older mark restored before a newer one
  restore-other-arena  a mark restored in another arena
  restore-after-reset  a mark from before a Reset()
  list-after-reset     a list used after its arena was reset (DebugChecks)
  list-grew-in-scope   an older list that grew inside a scope, used after it (DebugChecks)
  list-grew-in-place   an older list that grew in place inside a scope, used after it (DebugChecks)
  builder-grew-in-place  the same for a StrBuilder (DebugChecks)
  list-index           a list index out of range
  out-of-memory        an allocation the system can't satisfy (stopOnOutOfMemory)
  arena-limit          an allocation past an arena's maxCapacity (stopOnOutOfMemory)
  buffer-full          an allocation that doesn't fit in a FromBuffer arena (stopOnOutOfMemory)
  lambda-in-scope      a lambda first run inside AllocateObjectsHere, cached in the arena, then Reset (DebugChecks)
  lambda-in-open-scope the same inside OpenObjectScope, which frees it when the block ends (DebugChecks)
  scope-not-created    AllocateObjectsHere on an arena that was never created
  destroy-in-scope     an arena destroyed inside its own object scope
  throw                a throw, inside a try with a matching catch
  throw-null           throw null
  throw-in-static-constructor  a throw out of a static constructor, inside Catch.Run
  throw-in-parallel-for  a throw in a Parallel.For iteration, inside Catch.Run
  union-no-case        a switch on a union that holds none of its cases
  debug-assert         a Debug.Assert whose condition is false
  debug-fail           a Debug.Fail
  range-too-long       an array range that ends past the array
  bad-base64           Convert.FromBase64String on text that isn't Base64
  string-builder-range a StringBuilder.Remove past the end
  bad-pattern          Regex.Create with a pattern that isn't valid
  scratch-outer-scope  an Arena.Scratch scope allocating inside a nested one
  scratch-outer-list   a ScratchList added to inside a nested Arena.Scratch
  scratch-outer-text   a ScratchText appended to inside a nested Arena.Scratch
  ptr-null             the Value of a null Ptr
  ptr-after-reset      a Ptr used after its arena was reset (DebugChecks)
  pool-removed         a Pool handle used after its item was removed
  pool-moved           a copy of a Pool handle used after Move
  scratch-pool-outer   a ScratchPool added to inside a nested Arena.Scratch
  pool-other           a Pool handle used with another pool
  scratch-dict-outer   a new key in a ScratchDict inside a nested Arena.Scratch
  scratch-set-outer    a new item in a ScratchHashSet inside a nested Arena.Scratch
  builder-index        a StrBuilder index out of range
  builder-replace-empty  a StrBuilder Replace of an empty string
  scratch-outer-edit   a ScratchText inserted into inside a nested Arena.Scratch
  scratch-limit        an Arena.Scratch callback allocating past Arena.ScratchMaxCapacity
  scratch-buffer-full  an Arena.Scratch callback allocating past the end of its buffer
  scratch-stack-full   an Arena.ScratchOnStack callback allocating more than it asked for
  scratch-stack-size   Arena.ScratchOnStack with a size that isn't positive
  native-overflow      NativeMemory.Alloc with a count times size past the address space
  native-zeroed-overflow  the same for NativeMemory.AllocZeroed
  native-out-of-memory NativeMemory.Alloc of more than the system can give
  native-bad-alignment NativeMemory.AlignedAlloc with an alignment that isn't a power of two
  native-aligned-overflow  NativeMemory.AlignedAlloc of a size that overflows with the alignment
  pages-pointer-after-reset  a pointer used after its arena was reset (GuardPages)
  pages-object-after-scope   an object made in an object scope, used after it (GuardPages)
  pages-field-after-scope    the same, kept in a field of an older object (GuardPages)
  pages-span-after-scope     a span allocated in a scope, read after it (GuardPages)
  pages-scratch-pointer      a pointer into Arena.Scratch's memory, used after the callback (GuardPages)
  pages-after-destroy        memory used after its arena was destroyed (GuardPages)
  pages-arena-after-destroy  a copy of an arena's handle used after Destroy (GuardPages)
